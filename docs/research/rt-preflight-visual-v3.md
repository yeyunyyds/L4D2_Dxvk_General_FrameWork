# 合并视觉验收 v3

后续实测确认 v3 原始材质视图正确、自发光视图全黑；当前入口为 [UV 修正与独立光照 v4](rt-preflight-uv-lighting-v4.md)。以下保留 v3 的设计及发布历史。

针对用户结果 `rt-preflight-20261015-175621-a33a2cc2.zip`：B580 的 Ray Query、预期物体拾取和最终颜色读回成功，进程正常退出；但 PPM 只有 1～5/255，runtime 自己保存的 post-tonemapping DDS 也接近全黑，未出现预期橙色自发光三角形。旧版仅检查非黑和非恒定像素，会误把这组近黑噪声判为通过。实际游戏四个模块、7 个 Hook 和 3 个全局指针已取得候选证据，仍未做 ABI 调用或安装 Hook。

本次把颜色路径排查、视觉判据和平移控制合并到一个进程、一次 GPU 初始化和一个结果 ZIP。保留同一 runtime DLL 与三个大依赖，Windows CI 只编译小型诊断程序。更新覆盖原目录并保留 cache 即可。

| 自动项 | 相对对照 | 用途 |
| --- | --- | --- |
| baseline | 旧版默认不透明材质，强度 4 | 复现原问题 |
| explicit_blend | 显式 SelectArg1，保留材质颜色/alpha，禁用 alpha 混合，RGBA 写入 | 检查默认固定功能状态 |
| fixed_exposure | 在上项基础上使用全局 tonemap，关闭自动曝光，曝光偏移 0 | 检查曝光路径 |
| high_emission | 在上项基础上仅将自发光强度提高到 64 | 检查亮度尺度 |
| albedo | 默认强度 4 的原始材质调试视图 | 定位材质/表面输入，不算验收 |
| emission | 同材质的自发光辐射调试视图 | 定位发光/合成，不算验收 |
| translated | 选择前四项中原生初筛首次可见的正常路径，仅将物体沿世界 X 平移 1 | 排除旧帧、纯色或错误几何 |

每项使用独立的物体 ID 和回调存储，保存间隔 16 帧的两张最终画面。首项 128 帧，后续各 80 帧，共 608 帧；渲染仍有全局 240 秒上限，外部进程监控包含清理共 360 秒。先前 B580 初始化实测约 18 秒，共享初始化避免每项重启。帧数是诊断采样预算，不是性能结果。

独立 Python 检查实际 PPM 字节：640×360 RGB8，按已知相机投影反算三角形内部与外部，排除边缘区域；内部至少 65% 为可见橙色，外部至多 5%，内部平均红通道至少高出外部 20/255。橙色像素要求 R≥32、R≥G+12、G≥B+3。正常项两张图、对应物体拾取、成功清理必须同时成立；平移图必须符合新投影，并在离开/进入区域各至少 60% 像素有对应颜色变化。

这些阈值服务于固定的已知测试物体，不是普适画质评分。调试图正确不能替代正常最终画面。报告的 `next_focus` 是对照产生的排查方向，不能单凭一项变化就宣称已经证实根因。

退出码、CPU 窗口/DLL 生命周期与资源警告独立记录。上一结果有 `[40] common device objects were not disposed of.`，尚不能宣称无泄漏；v3 保留此警告，不把正常 Shutdown 当作释放全部资源的证明。

验收对象是独立 runtime 的静态可见着色与几何变化，不替代 [多线程实施计划](multithreaded-rt-implementation-plan.md) 的游戏内 G1/G2。游戏光追、实际引擎队列、保留多线程和性能仍待接入验证。用户只需运行 `run-test.cmd` 一次并上传一个结果 ZIP，无需 F8/F9 或手动动作。

新判据复核上一实际 PPM：内部/外部橙色比例均为 0，红通道对比约 0.143/255，正确判为失败。本地回归 51 项中 49 通过、2 项要求 Windows；原生测试与发布校验见 [验证记录](../../research/rt-preflight-v3-validation.json)。新版 B580 实测需由本次结果包确认。

代码 `20d4d6c` 已完成 Windows 验证：协调器 23/23，通过实际 x86 进程发现；游戏采集器 16 项中 15 通过、1 项 Linux 专用检查跳过。MSVC 14.29 的诊断、CPU 图像负面对照、真实 DLL 窗口清理、minidump 和标准 D3D9 拒绝均通过。包内 Python 实际加载原生 DLL、六个关键 DLL 独立加载、ZIP CRC、EXE/SHA 与源码逐字节核对均通过。已从发布提交 `b413ed312a4783a076fa85abb62f0f944f65eac7` 取回新包验证，大小 10939880 字节；三个大依赖保持原 SHA。以上原生检查未执行 B580 GPU。
