# v22：索引模型、DDS绑定复用与释放前清理

v21用户确认后半段普通感染者已经出现，但衣服颜色缺失。数据同时显示日志在463帧触及256MiB上限、39942次模型预算省略和18195次合成材质回退。此次将这些修正合并进同一份测试包，不要求原样重采v21。

## 模型与材质

- 使用原始索引转换为三角列表，保留三角形顺序、剔除方向、位置、UV及原顶点/接缝边界，避免每个三角形复制3个64字节顶点。
- 已审核的FLOAT3源法线优先；其他模型改用面积加权的逐顶点几何法线。这是明确的法线回退，可能改变旧版平面法线的照明，不能称为完整复现原材质法线或Toon。
- 生产C++在实际保存的156份模型输入上回放通过：591413源顶点、647425三角形，位置/UV/索引/绕序一致，法线有限且单位化。API几何从132074700降至45619532字节，约34.54%。仅为这些样本的字节量，不是FPS承诺。
- 256MiB活跃几何、96MiB单帧新增和8个运行期GPU查询限制不变；按本次超过500个模型部件的实际负载，把CPU/API句柄限额调至1024 Draw/帧、2048 Mesh、512 Material。
- 源引用仍限制128MiB编码字节代理/256引用；DDS文件与资源私有cookie绑定，关联记录不持有源COM引用。源引用淘汰后复用文件，避免反复读取和合成材质回退；cookie随资源销毁，防止COM地址复用错误。
- 游戏Surface写入、UpdateSurface和UpdateTexture会使旧cookie及活跃源缓存失效；新的内容重新导出，避免显示旧纹理。API材质仍依赖持久DDS文件，源引用淘汰不需要等待API的GPU查询；Mesh/Material回收仍有完成约束。
- DDS后台文件仍512MiB/1024份且保留至退出；诊断副本总64MiB，普通纹理最多48MiB，为感染者依赖和派生底色预留16MiB。优先请求可补存先前被省略的同一文件。
- 后半段全部人物保持中性、不透明底色，取消原合成金属/alpha0.4/自发光对照；感染者361–420帧仍有亮绿不透明双面对照。旧事件阶段ID保留以兼容分析，manifest另声明实际材质。
- 同时记录Infected和VertexLitGeneric近身候选，兼容模型替换路径；普通感染者实体身份仍需用户画面确认。

## 日志与退出

- trace v19（coverage22）对每个Present内的快照尾部和管线分别建立有界字典，记录所有Draw、转换报告和结果。不是抽样，原快照wire未修改；每帧最多4096定义，超出回退完整记录，256MiB文件保护仍保留。
- 对v21完整399330次Draw作无损重编码，分析器计数/转换/原footer一致：268436212降至146629132字节，约54.62%；按同一平均负载估算600帧190016153字节。实际未来场景负载可能不同，不能预先保证任意场景都不触限。
- beforeDeviceDestroy在safeDestroy前清理RT资源；主循环结束后也在其他退出清理前调用，尾部重复调用是空操作。日志/Reset等异常终止通过已注册回调主动回收。
- 清理时追加一个部分帧完成查询，避免只回收前一次Present；等待仍有1500ms上限。异常API结果或残留计数明确记录，不把超时回收当成功。仍不调用会强制释放游戏设备的standalone API Shutdown。
