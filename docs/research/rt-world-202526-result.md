# v7 实机：近处白墙与左侧结构恢复遮挡

本轮通过本镜头内近处白墙、左侧白色结构的 RT 覆盖恢复，以及前后两段的 HUD 对照。新增两种精确 LightmappedGeneric 布局后，颜色、primary RT 深度和解码法线共同出现对应表面，原来透出的远处结构被遮住。结果支持此前的场景布局覆盖诊断；不再需要围绕同一缺墙重复采集。

输入 `rt-world-20261016-202526-2f21b2d1.zip`，7,940,631 字节，SHA256 `2d281d5ac35bd46e2bf7e73bee29ec7fd4c21056cff5d04cf7ae0b81cc513f4b`。43 个成员、解压 101,765,718 字节，CRC 通过、无遗漏。安装 client/Host 哈希匹配已验证 v7 构建 `fe87baac495262a94c58974fdf0f398210e4d696`，身份 `ldb-rt-observer+81aa9f5383e0df38`。原始 trace/读回独立重析与上传报告一致；12 张预览均与原始 float 的独立映射结果一致。[结构化复核](../../research/rt-world-202526-review.json) 保存独立计数、区域深度/法线、状态关联和验收范围。

## 同一次采集中的变化

| 阶段 | 每帧转换 | 白墙及左侧结构 | HUD |
| --- | --- | --- | --- |
| 1–30 | 无，RT 关闭 | 原光栅可见 | 可见 |
| 31–120 | 13 次原 Lightmapped + 4 次 Unlit | 缺失，远处结构透出 | 可见 |
| 121–240 | 原 17 次 + 1 次 stride64 + 5 次 stride80 | 180/240 均恢复，遮住后方结构 | 可见 |

基线与扩展各只有一种转换世界相机，120/180/240 的相机矩阵完全相同；两段均保留 v6 的 Unlit/HUD 与同一强球灯，没有同时切换光源。原有 16 个材质身份的已采样 PS 是否绑定、纹理阶段/描述、渲染状态和 CULLMODE 在前后两段相同；样本没有比较 PS 字节码或纹理内容。变化集中于新增两种布局的 720 次转换：stride64 共 120 次、stride80 共 600 次，对应六个材质身份。原 CULLMODE 均为 3（D3DCULL_CCW），没有靠全局关闭剔除恢复物体。

这次镜头与上次 v6 起始位置不同，所有前后图像结论都在本轮内部对照，没有把不同回包的像素直接相减。

## 遮挡确实进入 RT 几何缓冲

颜色 120 中，右侧大白墙和左侧白色结构都缺失；180/240 中两者的纹理、轮廓与遮挡位置恢复。primary 深度和法线同时出现这些表面，支持实际几何恢复，而非仅有最后颜色覆盖。

选择避开 HUD 的白墙内部区域 `(350,60)–(470,180)`，共 14,400 个像素：

| 读回 | 有效深度命中 | 投影深度中位数 | 法线 |
| --- | ---: | ---: | --- |
| 120 | 7,735 | 0.992185 | 后方表面与未命中混合 |
| 180 | 14,400 | 0.959199 | 全部解码为 +Y 平面 |
| 240 | 14,400 | 0.959205 | 同一 +Y 平面 |

所有 7,735 个共同有效像素都变为明显更近的命中，投影深度至少降低 0.001，恢复了该墙应有的遮挡。左侧结构内部区域 `(115,95)–(230,145)` 的 5,750 个像素在扩展后也全部命中，深度中位数从 0.992980 降至约 0.982282，法线以近处 +Y 平面为主。

全图有效深度比例从 73.86% 变为约 87.28%～87.29%，这里只是该镜头的射线命中分布，不是整图/地图覆盖率。180 与 240 的有效遮罩 IoU 为 99.97%，共同命中像素法线夹角中位数 0 度，99.93% 在 5 度内，恢复后的几何总体稳定。

深度是投影 z/w，不是线性距离。控制段 RT 关闭时的 primary GBuffer 为空，不能把它当作原光栅深度真值。法线按固定 runtime 的 65534-offset 八面体编码独立解码，不能按普通 RGB float 或二补码 SNORM 解释。

## 稳定性与作用域

240 Present、76,777 Draw 快照全部有效，正常完成 reason=0；无 Reset、失败、未关联 Draw、viewport 不一致或 pipeline 查询失败。世界转换共 4,290 次，12,870 个捕获/应用/恢复 HRESULT 均为 S_OK。第 31 帧首次转换，控制段无转换。

HUD 共 210 次成功替换：基线 90、扩展 120，捕获/应用/draw/恢复均成功；120/180/240 的文字、弹药、血量等实际图像可见。逻辑 Draw/Present 有 77,017 个成功回报，其中 210 次原 Neko post 被透明 UI 触发调用替换，不能将这个总数全部称为物理原 Draw。

归属表有 66 组、无预算遗漏。38 份材质样本均能按 ordinal 对应到原 trace 的相同 material/table、shader、格式和原 CULLMODE，恢复后的 CULLMODE 与原值一致；纹理/渲染状态及 cull 查询无失败。该证据帮助核对范围与恢复，不提供屏幕逐物体 ID。两种格式一起加入，尚未把白墙或左侧结构分别精确对应到六个身份中的某一个。

Arc B580 运行时记录了 GBuffer/Direct/Indirect 的 Ray Query 和 ReSTIR GI 初始化。Bridge 两端正常退出，没有本轮 IPC fault 或崩溃迹象。退出仍有 40 个 common device objects 未释放，生命周期问题继续保留。诊断段包含 getter、文件记录和同步读回，首个 RT 编译有约 1.36 秒停顿；这些数据不作为生产帧率。

## 阶段结论与后续范围

本镜头的两处缺失静态结构已恢复 RT 遮挡，受限世界与 HUD 的画面链路得到进一步实机验证。此前“远墙在、近墙不在”的现象与尚未接入的场景布局有关，不能以距离或同属墙面推断它们走同一条处理路径。

保留 v7 作为已验证的受限世界/HUD 基线。后续优先补天空和可验证的普通刚性道具路径，再处理武器/人物等视角或蒙皮模型及原地图光照/材质；后续采集继续合并为一个入口、一次 F9、一个 ZIP，无需再单独重采这面白墙。

当前仍缺武器/手臂和天空，普通模型、透明/alpha 路径及其他地图区域未完整覆盖；诊断球灯不代表原地图光源，新增布局也没有把切线/UV2 接成完整 PBR。完整地图、精确阴影/GI、全分辨率画质、所有 UI/fade、Source 准备任务实际并行与生产性能均未验收。本轮只记录实机分析，没有发布新的二进制。
