# B580 GPU 相机重投影：静止、转头与补测平移

静止、转头、有效平移补测均完成 8 帧，设备记录为 Intel Arc B580。静止 32 张快照、转头 28 张、平移 8 张。静止/转头各有 16 张非清屏深度、7 对真正的 GPU 重投影，矩阵从同帧同目标的 cViewProj c8–c11 场景绘制取得。没有诊断错误、绘制记录截断或 Reset。部分边界未绑定 color/depth 时按设计跳过，转头最终阶段张数不同不影响这 7 对场景数据。

静止组 7 对共 1,555,302 个有效场景采样点全部通过深度一致性（设备深度容差 0.0001），原始 HDR 输出与所取上一帧样本完全一致，运动约为零。

转头组第一对矩阵未变，随后 6 对发生转动。共核对 738,169 个 GPU 有效点，运动与高精度 CPU 参考的最大误差约 0.000418 原渲染像素。6 对运动帧在相同 GPU 有效掩码上，RGB 预览误差的帧对等权平均从 17.3371 降到 1.41894，减少 91.82%。这是有效区域的对齐改善，不是全画面质量或插帧完成度。天空、越界及新显露区域仍为空，地面也有最近邻深度采样带来的条纹失配；尚未处理动态物体或遮挡补洞。

## 离线校验器修正

最初的校验器将 float64 参考选中的最近邻像素视为唯一合法输入。转头组 579,272 个运动有效点中，有 20 个颜色取样差异位于最近邻半像素边界；GPU float32 与 CPU float64 可落在边界两侧。不能把它们直接认作 GPU 颜色损坏。

修正仅在距离该边界不超过 0.002 个原渲染像素时检查相邻样本，并同时要求原始 HDR 四通道和对应深度严格匹配。没有放宽全局颜色阈值。包含相同颜色但深度不同的邻居，共识别 28 个相邻样本；接受样本的 HDR 误差为零，最大深度参考误差约 2.90e-7。JSON 分开保存唯一 CPU 样本的差异与边界处理后的结果。新增测试保证边界以外的邻居颜色不能蒙混通过，38 项测试通过。

修正的是分析工具，游戏二进制不变，补测平移继续使用当前 ZIP。ZIP 中旧分析脚本可能仍将这些边界点报作颜色不匹配；用户可以直接上传，由更新后的工具核对。

## 原平移组与补测

该组的 8 张都是 UNORM 最终画面，深度全部为 1，没有 HDR 场景绘制、深度写入或 cViewProj 场景候选，实际 GPU 对数为零。它只能验证文件结构，不能验证平移重投影。不能从日志断言游戏为何处于这种状态；用户已重新采集，有效补测目录为 `8940-44147859-1955600183168`。

补测包含 8 帧、32 张快照、16 张非清屏深度及 7 对 GPU 重投影，均通过文件、矩阵来源与 GPU/CPU 核对。7 对共 1,143,019 个有效 GPU 点；方向项保持不变，位置项变化。运动与 CPU 参考最大误差约 0.000407 像素，接受样本原始 HDR 误差为零，最大深度参考误差约 1.63e-7。7 对 RGB 预览误差等权平均从 3.34489 降至 1.25013，减少 62.63%；第一对只有约 3.18 像素运动，其余对运动中位数约 104–106 像素。补测同样有 21 个唯一 CPU 最近邻颜色差异位于舍入边界，经严格相邻颜色/深度核对通过。

## 下一阶段边界

静止、转头和平移共 21 对重投影，核对 3,436,490 个有效点，支持这三组 B580 Vulkan compute 相机重投影结果。下一步可继续实现全尺寸 GPU 常驻历史，以及天空、武器/UI 合成与遮挡处理。当前为 CPU 回读/上传的同步诊断，未生成中间帧，不作 FPS、延迟或性能结论。
