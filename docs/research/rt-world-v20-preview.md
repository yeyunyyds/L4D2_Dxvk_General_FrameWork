# v20：感染者48字节输入、分离纹理额度、诊断后60秒实时预览

针对162942实机结果，本版合并三项实现，保持一次F9和一个最终结果ZIP。原600 Present诊断及恢复段保留，随后自动重新启用RT，执行60秒中性材质预览，再等待已提交GPU工作的完成状态回收并恢复光栅。预览独立记账与三份颜色回读，不继续扩大逐Draw二进制trace。预览是有限时长实验，实际B580画面与稳定性尚待实机验证。

## 已实现

- Infected新增独立精确程序配置：VS `e9f1650bedd1575e46c486f522d3d0bb8a40e1abb8d78eb0d281daf93a267d72`、PS `3bac21dc89466c265f1c1411bd54bcdfeec8c0a9fafceab1b1891739384e7de7`、8元素声明及48字节主流布局。Shader常量c58..60驱动世界变换，c8..11仍执行相机证明；要求刚体变换，不按固定管线WORLD盲目定位。基础UV直接取原TEXCOORD0，不套用其他人物的UV变换。
- 将已审核Infected的FLOAT3源法线放入32字节规范顶点余下12字节，API网格构建器导入有效法线；零长度值逐顶点回退三角面法线。其他人物维持原有几何法线，未泛化未知打包法线/蒙皮程序。
- 纹理源工作集仍限128 MiB/256引用，容量压力时回收至少闲置2帧且旧使用已完成的条目。运行期DDS按内容去重，另限512 MiB/1024文件，保留至退出供后台加载。这个记账不能等同于真实GPU纹理驻留或总显存。
- 诊断DDS副本另限64 MiB；未留副本的绑定明确标记 `evidence_saved=false`，分析报告将其与已验证文件分开。运行期 `runtime-textures` 不加入结果ZIP，避免扩大贴图覆盖同步耗尽512 MiB归档额度；文件仍保存在本地结果目录，游戏退出后才可清理。
- API网格记录保留材质身份。已完成、闲置且不再被存活网格引用的材质可回收，避免只回收网格、材质持续累积至256条。
- 预览沿用每帧几何/查询上限和明确回退，单独日志有界采样；60秒后恢复段最多等待5秒，提前退出、Present/维护失败、缺少回读或未清空资源均不能判通过。客户端继续快照的条件与预览标记绑定，标记先于600帧完成标记发布，防止完成时停止快照的竞态。

Trace版本17、覆盖修订20，快照线格式保持不变；旧v19及更早结果的读取兼容保留。未修改Source生产端线程设置或物理组件。
