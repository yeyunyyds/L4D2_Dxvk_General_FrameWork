# v21：模型扩展与感染者集中验证

v20 的 API 提交与 60 秒预览运行成功，用户仍看不见近身普通感染者，因此可见性验收失败。旧样本主要是远处模型，不能把提交计数、受伤提示或包围盒投影当作近身实体可见证据。

## 本次实现

- 扩展 141352 捕获的 5 套完整 VertexLitGeneric VS：3 刚体、2 三权重骨骼。位置依赖保持 c13 morph → c58 骨骼/世界变换 → c8..11 裁剪，基础 UV 使用 c48/49。五套程序后段均未再改写位置依赖；额外指令影响照明、顶点色和雾。未知完整程序继续拒绝，不能仅按 shader 名或 stride 放行。
- 对 68 份实际输入、136072 顶点执行生产 C++，独立 float64 位置、UV 与相机证明通过。实样 morph 控制均为零；原生合成测试另验证非零 morph-before-skin。见 `research/rt-world-v21-model-replay-check.json`。
- 感染者 sampler0 是编码颜色输入，不能直接作为 albedo。按精确 PS `3bac21dc…` 重建 sampler0 两次采样、sampler5 调色板、sampler4 细节及 c3/c4/c10 材质参数；保留 VS c50/51 细节坐标与 PS 的 wz 交换。特别保留指令223/226 的 MOV_SAT 与 zxy 通道排列。
- 新 diffuse 结果与独立解释执行的原 SM3 指令176–294对照，33套实样常量、1750组随机纹理返回值通过，最大绝对误差约1.93e-7。见 `research/rt-world-v21-infected-material-check.json`。
- 输出为最多256×256线性BGRA8不透明DDS，生成完整 mip，每帧最多1份、最多128种依赖/参数组合。未知/不可读依赖或预算不足明确中性回退。所有源与派生DDS共用512MiB后台文件、64MiB诊断副本预算；后台文件保留至进程退出。
- 感染者361–420帧自动采用亮绿不透明自发光、双面几何对照，其他模型保持原阶段。其余感染者阶段和60秒预览使用重建底色或明确中性回退，避免把编码alpha当作表面透明度。诊断事件区分原始cull与API实例cull、感染者材质覆盖。
- 每60帧优先保留距相机1024 Source单位内的感染者，最多4份/帧、256条、16MiB额外几何。诊断及预览都记录，结束输出各 shader 提交/拒绝原因。投影中心不是三角形遮挡测试。
- 拒绝模型自动补存有界原始VS/PS、常量、声明、geometry和auxiliary/morph证据，覆盖预览期间的新程序，最多32份、16MiB；不增加用户采集轮次。
- `infected-analysis.json` 校验近身几何、依赖链、透明度和最终计数。缺失诊断DDS显式标记，不会冒充贴图文件已完整验证。

## 集中测试

仍用一次F9：先让普通感染者出现在近处画面，再开始；缓慢转头、移动并覆盖人物、武器和静态场景。600帧诊断后自动60秒预览，期间可再次召唤感染者。等控制台要求退出再退出，上传退出分析完成后的同一个最终ZIP。

## 验收边界

当前扩大的是已审计程序与底色依赖覆盖，不是“所有材质/实体均已接入”。未知程序、完整Toon/PBR、透明材质、全地图、长期稳定性、性能和Source生产端并行准备仍未验收。基础级低分辨率烘焙不复现原片元导数/各向异性LOD；排除原顶点光照、屏幕AO和雾，避免重复烘焙光照。下一份B580实机画面必须确认普通感染者在亮色对照和正常底色阶段分别是否可见；数值回放不能代替这个结论。不改物理组件或Source线程设置。
