# v15 实机：六组模型对照均失败，完整同帧输入将排查范围推进到后端交接

本轮模型画面验收失败。世界基线可辨；加入模型后出现大面积青色噪点与异常三角形，preserve 关闭、开启、再次关闭均未消除问题。合并普通模型后，人物轮廓也未稳定保留；中性灰模型和定向灯对照继续异常。撤去模型后，青色消失、背景几何恢复可辨，但亮度仍与最初基线不同。

## 后续应验证实际GPU交接，减少重复进图收集

已经验证的是原输入、CPU重建，以及公开D3D9设备上的映射上传读回与绑定。GPU随后真正消费的VB/IB副本、缓冲生命周期、后端几何/实例及BLAS/TLAS内容仍未被直接证明正确。固定后端即使关闭preserve，仍会使用几何与实例缓存；不能把一次开关失败解释成整个缓存体系已经排除，也不能从CPU数学通过推断GPU上传和异步消费必定正确。

下一步应使用本次105份完整同帧输入建立固定的GPU模型重放，优先比较明确的持久资源所有权、实际后端消费的数据和稳定实例标识；必要时增加公开Mesh/Instance API直入对照，将legacy D3D9自动转换与后端公共渲染路径区分开。先修几何交接，再扩大更多材质家族。现有输入足够准备复现，无需原样重采v15；后续硬件验收继续合并在一个入口内。Source线程设置继续保留，准备线程并行与生产性能仍未验收。
