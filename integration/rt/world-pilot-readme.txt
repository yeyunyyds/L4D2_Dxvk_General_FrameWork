一次 F9 自动完成，一份最终 ZIP：
1. 解压到独立目录，放在旧包旁；保留旧包 backups 和 installed-observer.json，供自动继承原始恢复备份。
2. 双击 run-test.cmd，让脚本安装配套 x86 client/x64 Host 并通过 Steam 启动。固定 runtime 校验后复用。
3. 进入原测试地图，让墙、天空与人物同时可见，按一次 F9。缓慢转头、移动，让人物动画继续。600 Present 自动结束，首次初始化可能停顿。
4. 按提示正常退出，等控制台显示最终 COMPLETE / INCOMPLETE 和 ZIP 路径。上传该最终 ZIP，勿手动压缩中间目录。结果 ZIP 使用无损 LZMA 压缩减小上传大小；如需打开，可用 7-Zip。

本轮修正：
- v16 在第339帧达到每帧128次模型提交，触发了测试保护。该上限现为512；这不是显卡显存容量。
- 新帧第一次模型提交前先轮询完成标记，回收 GPU 已完成、闲置两帧的旧 Mesh，减少创建新姿态时的瞬时几何占用。Present 后仍继续检查；未完成的资源不能提前释放。
- 总展开几何256 MiB、单帧新增96 MiB、512缓存项、最多8个未完成查询保持有界。预算不足时，仅遗漏受影响的模型提交，记录具体原因、每帧及总数，继续世界/天空和其余对照；额度释放后自动恢复。真实 API 或状态错误仍停止 RT。
- COMPLETE 只表示采集完成。summary.json 中 model_budget_omissions 非零时，模型覆盖明确为 partial_due_to_budget；不要当作全覆盖验收。
- 失败记录包含 frame、Draw ordinal、API操作、具体预算、几何字节、缓存项及未完成查询数，避免再用同一个错误码猜原因。

模型仍为当帧 CPU 重建姿态 → CreateMesh / DrawInstance；刚体变换复用 Mesh，姿态变化更新几何。原始 Draw 只执行一次，作用域 Ignore 排除旧模型转换，结束后恢复原值。
Source 线程 CVar 和准备路径不变，不替换物理引擎。

模型继续使用合成材质、面法线和原UV。原模型贴图、完整 Toon/法线贴图、原照明、全部透明与第一人称特殊通道尚未接入。本轮不改灯光/曝光；人物偏白还需后续材质与照明校准。
当前仍有完整 shader、矩阵、骨骼、morph、主相机和特殊通道筛选，未覆盖模型可能缺失。
每个模型探针最多64份摘要；两组中性灰各共享16 MiB几何预算，其中前一帧最多8 MiB，其余材质阶段只保存哈希和状态。完整原输入另有有界审计。
