LDB 1.3.2：受限世界 Remix 接入试验 v15（模型缓存兼容与材质/灯光合并对照）

一个入口、一次 F9、一个最终结果 ZIP：
1. 解压到旧测试包旁的独立目录，保留旧包 backups 和 installed-observer.json，供自动继承原始恢复备份。
2. 双击 run-test.cmd，等待脚本安装配套 x86 client/x64 Host 并通过 Steam 启动游戏。固定 runtime 校验后复用。
3. 进入相同地图，选天空、墙、武器与人物同时可见的位置，按一次 F9 后保持镜头不动。人物动画可继续；600 Present 自动结束，首次 RT 初始化可能停顿。
4. 按提示正常退出游戏，等控制台显示最终 COMPLETE / INCOMPLETE 和 ZIP 路径。只上传 results 中最终 rt-world-*.zip，不要手动压缩中间目录。

所有对照自动执行，不需要额外按键：
- 1–30：光栅控制，RT 关闭。
- 31–120：既有 v7 世界/Unlit/切线布局与 HUD。
- 121–180：加入完整位置/UV 重建天空，不加入扩展模型。
- 181–240：仅 Neko，关闭后端 preserve 转换复用，沿用球灯和首层贴图。
- 241–300：仅 Neko，临时开启 preserve 作为对照，其他条件不变。
- 301–360：仅 Neko，再次关闭 preserve，检查是否恢复。
- 361–420：普通模型与 Neko 合并，关闭 preserve；球灯和首层贴图。
- 421–480：同一合并路径，仅将模型 RGB 改为中性灰；保留原贴图 alpha、alpha test、剔除和深度，世界材质不变。
- 481–540：恢复模型首层贴图，球灯改为定向诊断灯。
- 541–600：撤去扩展模型，恢复原球灯，检查背景能否恢复。
30/120/180/240/300/360/420/480/540/600 自动保存 640×400 颜色、深度、解码法线与原始读回。

本次修正与验证范围：
- 默认关闭固定 Remix 后端的 preserve 转换复用，仍请求 staging 复制。中间一个阶段临时开启以检验该候选原因；不修改 Source 线程 CVar，不移植全局 prim context。
- 曝光不变。人物中性灰只作材质诊断；定向灯只作照明诊断，不代表恢复原地图光照或完整 Toon。
- 保留 v14 独立、紧凑、可读 VB/IB，上传只读比较和 Draw 前绑定核验；完整 shader 身份、三权重、morph、主相机证明及特殊通道筛选不变。
- 中性灰状态使用作用域恢复；任何捕获、应用或恢复失败均记录。配置请求失败则停止 RT/采集，不把失败阶段标成正常。

同一个 ZIP 自动补齐的证据：
- 在六个模型取图帧逐次绘制记录最多64份提交，不再按材质去重，避免共用材质的不同部件被漏掉。
- 三个 Neko 对照各预留12 MiB完整原输入/重建配对，合并贴图阶段16 MiB；中性灰/定向灯阶段只记录摘要和状态，不重复保存完整几何。
- 记录完整重建 VB/IB 哈希、实际提交的首阶段颜色/alpha 状态、texture factor、sRGB，以及原始 clip/stencil/cull/深度和自定义 Remix 字段。超预算明确标记，不当成完整对象证明。
- 原始输入审计继续每大阶段最多198份；末阶段包含全部模型子阶段，最终汇总。PS常量224个float4、完整morph；其他辅助流仍为256字节前缀。

v14 合并阶段已出现完整人物和武器，但 Neko 单独阶段仍白屏并有异常长条。本版对这些候选路径作兼容修正和合并验证，尚需 B580 实机验收。上传核验是设备可读映射核验，不是 GPU BLAS/TLAS 读回；转换计数、CPU 回放及 Windows NULLREF 检查不等于画面正确。
