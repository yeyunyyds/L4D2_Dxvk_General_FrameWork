LDB RT World Pilot v21 — 更多模型程序、感染者颜色重建与近身目标集中验证

测试步骤（一次F9）
1. 解压到新文件夹，运行 run-test.cmd，按提示安装双端文件、启动游戏并进入测试地图。
2. 先让普通感染者出现在近处视野中，再按一次F9。可缓慢移动、转头；尽量同时看到人物、武器和静态场景。
   预览期间也可继续召唤普通感染者并观察；无需追加采集按键。
3. 原600帧诊断结束后，自动进入60秒中性材质实时预览。继续正常移动，无需第二次按键。
4. 等控制台提示预览完成、要求退出后正常退出游戏；保持控制台开启，等待最终 ONE ZIP 路径，再上传该ZIP。
请勿在60秒预览期间提前退出或手动压缩尚在写入的目录。完整结果ZIP会在退出与分析后更新。

600帧诊断：1–30原光栅；31–120世界/HUD；121–180天空；181–240 Neko贴图；
241–300组合模型贴图（含符合已审核程序/布局的感染者），头灯30；
301–360中性材质低照明3；361–420其他模型金属、感染者亮绿不透明自发光双面对照；421–480其他模型合成半透明；481–540其他模型自发光；541–600移除API模型并检查回收。
随后自动重新开启RT，继续60秒中性材质预览（头灯30），最后按GPU完成状态回收并恢复原光栅。
预览单独记录，不继续扩张逐Draw二进制trace；包含开始、中段和结束前的三份颜色回读。

v21新增（同一轮自动执行）：
- 接入141352数据中的5套VertexLitGeneric完整VS身份：3套刚体、2套三权重骨骼；仍检查声明、morph和相机。
  68份实际输入、136072顶点已通过生产C++位置/UV/相机回放；实际GPU画面待本轮验收。
- 感染者按已审核PS的sampler0编码、sampler5调色板、sampler4细节及材质常量重建底色。
  输出线性BGRA8、不透明；每份最多256x256，生成完整mip；每帧最多烘焙1份、总共128种组合。
  缺依赖或超预算明确使用中性回退，绝不再把编码alpha当作表面透明度。
  不复用原顶点光照、屏幕AO或雾到RT底色；低分辨率基础级烘焙仍可能有细节/采样偏差，不是完整原PS复现。
- 感染者在361–420帧自动换成亮绿不透明自发光双面几何对照，其余模型阶段和60秒预览使用重建底色/中性不透明回退。
- 近身感染者每60帧取样，距相机中心1024 Source单位内优先保留，每帧最多4份、全程256条/16MiB额外几何证据。
  60秒预览期间仍记录此证据和最终各shader成功/回退计数；原有限额不会被无限扩张。
- 未覆盖模型在诊断和预览中自动补存完整VS/PS、常量、声明及有界几何，最多32种/额外16MiB，存入unknown-model-inputs.jsonl。
- infected-materials.jsonl保留调色板/细节依赖与常量；infected-analysis.json核验文件和计数。
  贴图证据缺失明确标为omitted，计数、投影中心或受伤提示均不等于感染者实际可见。

保留的v20机制：
- Infected仅放行已审核的完整VS/PS身份及48字节声明，依据c58..60世界矩阵和c8..11相机重建。
  保留原基础UV，有效FLOAT3源法线导入；零法线按顶点回退三角面法线。其他程序/布局仍明确回退。
- 纹理活跃源缓存128MiB/256引用；完成旧帧后可回收闲置源引用。无剩余网格引用的闲置API材质也在完成后回收。
- 运行期DDS后台文件最多512MiB/1024份，按内容去重，保留至退出以供后台异步加载；这不是GPU显存承诺。
  诊断DDS副本另限64MiB，runtime-textures不加入ZIP。未保留副本的绑定以evidence_saved=false明确记录，不能称为已完整验证贴图文件。
- 复制源纹理已有的全部mip，不生成缺失尾级；DXT1/3/5压缩块原样保留，X8转BGRA且alpha固定255。
  单基础级最多16MiB，整链最多24MiB；每帧至多4次新读取、24MiB加文件头。额度不足时保留明确合成材质回退。
- 几何限制仍为256MiB活跃、96MiB单帧新增、512 Draw/帧、512 Mesh、8个待完成查询；超限只遗漏相应模型并计数。
