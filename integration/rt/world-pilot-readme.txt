LDB RT World Pilot v20 — 感染者、纹理工作集与有限时长实时预览

测试步骤（一次F9）
1. 解压到新文件夹，运行 run-test.cmd，按提示安装双端文件、启动游戏并进入测试地图。
2. 回到游戏按一次F9。可缓慢移动、转头和继续人物动画，尽量让感染者出现在视野中。
3. 原600帧诊断结束后，自动进入60秒中性材质实时预览。继续正常移动，无需第二次按键。
4. 等控制台提示预览完成、要求退出后正常退出游戏；保持控制台开启，等待最终 ONE ZIP 路径，再上传该ZIP。
请勿在60秒预览期间提前退出或手动压缩尚在写入的目录。完整结果ZIP会在退出与分析后更新。

600帧诊断：1–30原光栅；31–120世界/HUD；121–180天空；181–240 Neko贴图；
241–300组合模型贴图（含符合已审核程序/布局的感染者），头灯30；
301–360中性材质低照明3；361–420金属；421–480合成半透明；481–540自发光；541–600移除API模型并检查回收。
随后自动重新开启RT，继续60秒中性材质预览（头灯30），最后按GPU完成状态回收并恢复原光栅。
预览单独记录，不继续扩张逐Draw二进制trace；包含开始、中段和结束前的三份颜色回读。
