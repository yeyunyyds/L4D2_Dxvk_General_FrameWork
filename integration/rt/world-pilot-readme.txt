LDB RT World Pilot v23 — 优先补齐人物、服装贴图与普通透明部件

测试步骤（仍然一次F9）
1. 解压到新文件夹，运行 run-test.cmd，按提示安装双端文件、启动游戏并进入测试地图。
2. 让普通感染者出现在近处视野中，再按一次F9。缓慢移动、转头，尽量同时看到人物、武器和静态场景。
3. 600帧诊断后自动进入60秒中性材质预览；继续观察人物衣服、头发及透明部件，无需再按F9。
4. 等控制台提示要求退出后正常退出游戏；保持控制台开启，等最终 ONE ZIP 路径出现，再上传同一个ZIP。
不要提前手动压缩尚在写入的结果目录。开始几帧仍可能因贴图加载出现回退，应重点观察后半段和预览。

本版目标是显示覆盖，帧率暂不作为通过条件；仍不能预先宣称所有人物和材质已完整显示。

600帧阶段：1–30原光栅；31–120世界/HUD；121–180天空；181–240 Neko；241–300组合模型；
301–360低照明；361–420感染者亮绿双面对照；421–540恢复正常底色及源透明；541–600回收。
随后60秒预览保持正常底色、源透明与头灯30，自动恢复原光栅。预览有三份颜色回读，不扩张逐Draw日志。

v23合并修正：
- 运行期DDS文件按需上限改为4GiB/4096份，不是显存分配，也不会启动即占满。
  普通来源最多使用3.75GiB/4032份，为感染者依赖及派生底色保留256MiB和64份文件。
  按内容去重，文件保留供后端异步加载；runtime-textures仍不加入结果ZIP。
- 资源版本因容量被拒绝后记住结果，不反复读回、不占后续新读取额度；游戏更新资源时使此状态失效。
  每帧最多16次新读取、96MiB加16个DDS头，失败的读取同样计入字节限额。源引用仍128MiB/256份。
- 不降低源纹理分辨率，复制已有全部mip；单级16MiB、整链24MiB，4096最大维度限制不变。
  诊断DDS副本仍64MiB，普通48MiB，感染者优先剩余16MiB；证据不足明确记录evidence_saved=false。
- 几何改为512MiB活跃、192MiB单帧新增；1024 Draw/帧、2048 Mesh、512 Material及8个待完成查询不变。
  仍使用索引模型、源法线/面积加权回退，并依据GPU完成状态回收。
- 增加已审核21a83646…三权重VertexLitGeneric程序，实际230顶点位置/UV回放及原64样本回归通过。
- 已审核普通模型可接入SRCALPHA/INVSRCALPHA/ADD、无单独alpha运算的透明路径；保留源DDS透明度和alpha test。
  不再使用合成0.4透明度。加法、预乘、深度专用、stencil/裁剪等特殊路径继续明确拒绝。
  Infected的alpha是编码数据，仍走已审核的专用底色重建，不按普通透明处理。
- 贴图绑定记录源材质/shader，近身记录API材质句柄及是否带纹理；未知模型输入同时保存混合/深度状态。
  近身优先已就绪、视野内的Infected及至少512顶点的三权重模型，减少小型道具抢占；仍不等于感染者实体身份。
