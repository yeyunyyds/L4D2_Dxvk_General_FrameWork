LDB 1.3.2：世界与实时模型 Mesh API 接入试验 v16

一次 F9 自动完成，一份最终 ZIP：
1. 解压到独立目录，放在旧包旁；保留旧包 backups 和 installed-observer.json，供自动继承原始恢复备份。
2. 双击 run-test.cmd，让脚本安装配套 x86 client/x64 Host 并通过 Steam 启动。固定 runtime 校验后复用。
3. 进入原测试地图，找墙、天空与人物同时可见的位置，按一次 F9。可缓慢转头和移动，让人物动画继续；600 Present 自动结束，首次初始化可能停顿。
4. 按提示正常退出，等控制台显示最终 COMPLETE / INCOMPLETE 和结果 ZIP 路径。只上传该最终 ZIP，勿手动压缩中间目录。

自动对照阶段：
1–30 光栅控制；31–120 既有世界与 HUD；121–180 加入重建天空。
181–240 仅 Neko 模型中性灰；241–300 普通模型与 Neko 合并中性灰。
301–360 粗糙材质；361–420 金属；421–480 半透明；481–540 自发光。
541–600 撤去 API 模型并等待已完成的 GPU 资源回收，检查背景恢复。
10 个阶段取图帧自动保存颜色、深度和解码法线。镜头可运动，阶段之间画面差异不能直接归因于材质。

模型改为当前帧 CPU 重建姿态 → Remix CreateMesh / DrawInstance。刚体仅更新实例变换，姿态改变创建新 Mesh。
同一个原始模型 Draw 保留且只执行一次，以作用域 Ignore 标记避免旧转换路径重复收集，随后恢复原状态。
Mesh 仅在 GPU EVENT 查询完成、且满足缓存闲置条件后销毁；总量、每帧新增、提交数量及未完成查询均有上限。超限停止 RT 并保留失败日志。
Source 线程 CVar 和准备线程路径不变。本轮不替换物理引擎。

本版模型使用合成材质与面法线，不含原模型贴图、完整 Toon、法线贴图或真实地图照明恢复；半透明是人工材质响应对照，不代表透明模型已完整支持。
原有世界/天空路径继续保留。模型仍要求完整 VS/PS 身份、矩阵/骨骼/morph 证明、主相机与特殊通道筛选；未覆盖模型可能缺失。
每个模型取图帧最多记录64份摘要，240/300各最多16 MiB紧凑几何，其余材质阶段仅保留哈希与状态。完整原始输入另有有界审计。
日志记录逐 Present 创建/复用/销毁与 GPU 完成进度，后台收集与截图不等于画面正确；B580 实时游戏、全面覆盖、长期稳定性和性能仍需验收。
